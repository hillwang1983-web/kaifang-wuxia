# 公网试玩统一更新

用户授权：从 GitHub 拉最新版本、跑测试、更新公网试玩，省去手工拷贝。

范围为青石渡 V0.4 现有 launchd 服务。采用本机单命令：fetch 指定远端分支→按固定提交还原临时目录→锁文件安装与 V0.4 测试→备份旧 app/清单→替换并 kickstart→本机提交号/四资源哈希验证→公网入口与鉴权验证→保存成功回执。默认 origin/main；不清理开发工作区，不自动合并分支。

锁覆盖整个更新过程；测试失败不触碰运行目录；切换或检查失败自动恢复旧 app/清单、重启并验证旧版。保留失败版本和备份以供诊断。只更新本游戏，不操作账号、存档或其他服务。

公网受登录保护；脚本不用真实账号，公网证据限定为看板健康、登录入口和未登录拦截。精确版本以本机运行提交号与文件哈希验证，不声称公网登录后试玩已自动验收。

成功条件：发布事务与锁的测试通过；完整 V0.4 回归通过；远端提交实际发布，运行资源哈希一致；失败时非零退出并保持/恢复旧版。
