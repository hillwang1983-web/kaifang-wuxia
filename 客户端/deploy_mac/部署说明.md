# 网金网页客户端 · macOS 部署说明

这个包是**浏览器里玩的网金客户端**：一个本地网关（`gateway.py`，把浏览器的 WebSocket 转成原版游戏协议）加一个网页（角色状态、地图、人物精灵、聊天、移动、传送、装备、吃药、商店）。
它连的是**游戏服务端**（网金新服务端 `jyserver`，另有一个 Mac 部署包）；原版 Windows 客户端 `loginp.exe` 和登录器**不在**这个包里。

运行时**只用 Python 标准库**即可玩城镇 / 室内地图。**野外大地图**（`bigmap.py`，5000 一类 1000–8000 号图，含出城后的路）需要 numpy + Pillow：

```bash
python3 -m pip install numpy pillow
```

没装的话大地图会被网关取消（提示一句），其它功能照常；包里已带大地图资源（`share/pic/MapMrg*.Mrg`、`Pan_J*.mrg`、`Pan_Com*.mrg`、`ScenePic.mrg`、`KcomMrg*.mrg`：地面 + 城墙 / 建筑 / 树等物件，约 110MB）。Python 3.14 上 numpy / Pillow 若装不上预编译包，就装 `python@3.13` 并用 `PYTHON=python3.13 ./start_client.sh`。

## 1. 安装 Python（3.10 以上，3.14 已测）

和服务端那边装同一个就行（服务端要求 3.14）：

- 官网安装包：https://www.python.org/downloads/macos/ ，或 `brew install python@3.14`
- 确认：`python3 --version`；如果 `python3` 版本太旧，启动时用 `PYTHON=python3.14 ./start_client.sh` 指定。

## 2. 解压

把 `jyclient-mac-*.zip` 拷到 Mac，双击解压（或 `unzip jyclient-mac-*.zip`），得到 `jyclient-mac/`。

```bash
cd ~/jyclient-mac
```

**以后更新只拷增量包**：`jyclient-mac-update-*.zip` 只装改过 / 新增的文件（通常几百 KB），是相对最近一个完整包的累计改动——拿最新的一个就够，不用按顺序装。先停掉网关，再在 `jyclient-mac/` 的上一级目录解压覆盖：

```bash
unzip -o jyclient-mac-update-*.zip -d ~
```

包里的 `jyclient-mac/更新说明.txt` 写了底包是哪个、改了哪些文件。底包和你 Mac 上装的完整包不是同一个时，要么先装那个完整包，要么让打包的人用 `--update <你装的那个包>` 重新打。

## 3. 先启动游戏服务端

在**另一个终端窗口**里，按服务端包（`jyserver-mac-*.zip`）自带的《部署说明》启动，默认监听 6731：

```bash
cd ~/jyserver-mac && ./start.sh
```

看到 `listening on 0.0.0.0:6731 ...` 即可。

## 4. 启动网关，打开浏览器

```bash
./start_client.sh
```

看到类似：

```
网关 http://127.0.0.1:8088/  ->  游戏服务端 127.0.0.1:6731  （物品名 17445 条，地图背景 635 张，外观码 4947 条）
  物品表 .../data | 地图 .../share/pic | 外观表 .../share/dat/Item3.Dat | 精灵缓存 .../web/sprites
  碰撞格 1232 张地图（dat\WSG*.dat）
```

就是好了（如果出现"警告：有资源没读到"，按下面的路径检查包有没有解压完整）。然后在浏览器里打开：

**http://127.0.0.1:8088/**

- 第一次启动时 macOS 可能问"是否允许 Python 接受传入网络连接"：网关默认只监听 127.0.0.1，选**允许**或**拒绝**都不影响本机使用。
- 页面右上"网关已连接"后，在左上输入**账号 jyid**，点"登录"。服务端包里带的测试号有：`8617293`、`1234567`、`123456`（协议本身没有密码，只信 jyid）。
- 想用两个角色互相看：开两个浏览器窗口（或一个普通窗口 + 一个隐私窗口），各登录一个号。
- 停止：在启动网关的终端里按 `Ctrl+C`（网关断开时会自动让角色下线，服务端存档）。

### 连别的服务端 / 改端口

```bash
SERVER=192.168.1.20:6731 ./start_client.sh        # 服务端在另一台机器上
LISTEN=127.0.0.1:9000 ./start_client.sh           # 网关换端口
./start_client.sh --look-fallback                 # 打开外观兜底（见下），其它参数照传给 gateway.py
```

**不要把网关监听到局域网 / 公网**（`LISTEN=0.0.0.0:8088`）：游戏协议登录只认 jyid、没有密码，网关也没有鉴权，能连到的人可以用任何账号登录。
要给别人用，请放在带认证的反向代理后面，或者先在网关里加登录校验。

## 5. 页面上能做什么

整个窗口就是地图，信息以浮层的形式叠在上面：

| 位置 | 内容 |
|---|---|
| 全屏背景 | 原版地图图片 + 人物精灵（带名字，说话时头顶冒气泡）。**滚轮缩放**（也可点右下角 − ＋），默认 1.25 倍 |
| 左上 | 角色小面板：名字、精 / 血 / 神 / 内四条、所在地图和坐标、金钱 |
| 顶栏的页签 | **角色**（属性、状态）、**背包**（装备可脱下；药品"使用"；装备选槽位后"穿"）、**技能**、**商店**（选商人 → 打开 → 买）、**传送**（地图号 + 坐标；按坐标走路；同图玩家列表）、**设置**（显示碰撞格、名字、调试帧） |
| 左下 | 聊天和系统消息；回车说话 |
| 右下 | 小地图（黄框 = 当前视野，红点 = 自己，蓝点 = 别人），**点小地图也能走过去** |

**走路**：点击地图或小地图，角色会自己绕开建筑和不能走的地形，走一条拉直的路（黄色虚线是路线）；点到不能走的位置会走到最近的可走点。
碰撞数据来自客户端的 `dat\WSG*.dat`（每张图一个 20×20 像素格的位图），在"设置"里勾"显示碰撞格"能看到红色的挡路区域。
网关也会拦住穿过阻挡格的移动（"这条路被地形挡住了"）；传送 / 登录落在阻挡格上不受限，之后只要求走到能走的地方。
没有碰撞数据的地图（WSG 里没有这张图）直接走直线。
人物走到建筑 / 树的后面时会被遮住（只剩名字），用的是原版地图的前景物件图（`web/objects/`，来自 `Scene*.mrg`）。

## 6. 现在的限制（先看这几条，免得白找）

- **人物外观不完整**：外观按原版客户端的机制取（`Item3.Dat` 里的外观码）。服务端自己的 GM 装备和武器编号（25091、27181、12498 等）**不在**客户端的外观表里，原版客户端对它们什么也不画，所以这些号的人物只显示身体（连头发都没有）。
  `./start_client.sh --look-fallback` 可以让**武器**按类型（刀 / 棍 / 枪 / 剑 / 鞭）兜底画出来——这**不是原版行为**，默认关闭。头盔、衣服没有兜底。
- 所有人物都用同一个男性模型（boy01）。性别 / 模型字段在测试号上没有变化样本，没法确认哪个字段决定模型。
- NPC 和怪物只有**名牌**：地图上用金色菱形 + 名字标出 NPC 的位置（原版 `NpcMrg*.Mrg`），"设置"里可开红色的怪物刷新点。NPC 的精灵（人形）没找到对应表，所以没有画像。
- **NPC 对话**：点有事件的 NPC（名牌旁走过去会自动开口），底部弹出对话框——点击 / 回车 / 空格翻页，选单点选项或按数字键，Esc 离开。对话文字、选单、"随机说一句"、买卖（打开商店）、任务标记 / 物品 / 属性变化（由服务端执行）都是用原版 `EvtMrg*.Mrg` 事件脚本 + `TextMrg*.mrg` 对话文本跑出来的。
  还没做的动作：NPC 对话里战斗动作只取第一种对手（数量按事件里的填，最多 5 只）、彩票 / 拉霸 / 时间类等少数动作（显示"未实作的动作 N"）。个别条件的判断是按已验证的数据推的（见 `客户端库说明.md`），所以极少数 NPC 可能说出和原版不同的那一句。
- **钱庄 / 丢弃 / 拾取 / @指令**：顶栏"钱庄"页签存取物品（只存物品，不存钱）；背包每件物品有"存"（数量框）和"丢"；地上的东西是蓝色小方块，点一下捡；聊天框输入 `@where`、`@cpw`、`@scb 1` 等原版文字指令（回复显示在聊天框）。看不到自己进图之前别人丢的东西。
- **社交 / 账号全套**（服务端支持的通信接口都有入口，覆盖表见 `python3 api_map.py`）：
  - 聊天框左边的下拉选频道：公共 / 队伍 / 组织 / 私聊（私聊选对象，或在"社交"页点同图玩家的"私聊"）。
  - "社交"页：同图玩家（私聊 / 组队邀请 / 招收进组织 / 发起交易）、队伍（创建 / 离队 / 解散，收到的邀请点"接受 / 拒绝"）、组织（创立 / 退出 / 刷新在线成员 / 踢人，收到的招收点"加入"）。
  - "交易"页：双方放物品 / 金钱 → 锁定 → 确认成交；成交后网页会自动**重新登录一次**同步背包（原版没有刷新包）。
  - "武功"页：装备到槽 0–14、删除（要账号密码，原版只把等级清零）；"账号"页：改外号、二级密码验证、物品信息；背包里每件物品还有"卖"（VIP 回收）。
  - 登录栏有**密码框**（缺省 = 账号，测试号都是这样）和"删角色"；**新账号**登录后会弹出"新建角色"：摇点、检查重名、出生地、头像、生日、属性（总和 ≤ 145）。
  - 隔离测试服务端里有一个没有角色的账号 9000001（密码 pw9000001）可以试新建角色流程。
- 战斗：直接点地图上的怪（走到旁边自动开战，打赢后这只怪隐藏 60 秒），或侧栏「战斗」页（选怪 → 遭遇 → 战场浮层 → 点怪 / 空格出招 → 怪自己出招 → 掉落自动拾取 → 约 15 秒后结算）。需要服务端是 2026-10-19 之后带单人战斗的版本；旧服务端会提示"服务端没有开战"。伤害 / 掉落 / 怪的出手间隔都是自定的数值，不是原版公式。打输后气血记为 1（服务端规则），可以再战。包里的 `combat_server.py` 是验证用的假战斗服务端，不用管。
- 没有：攻击 / 受击 / 骑乘动画。
- 页面只测过 Chrome / Edge；Mac 上用 Safari 理论上可以，没测。

## 7. 包里有什么

```
jyclient-mac/
  start_client.sh        启动网关
  gateway.py             HTTP + WebSocket 网关
  jyclient.py            客户端协议库（asyncio）
  packet_proxy.py        帧编解码（网关用）
  parse_0x1e.py          登录角色状态包解析
  npcdata.py             地图 NPC 摆放解析（读 share/pic/NpcMrg*.Mrg）
  evtdata.py evtengine.py  事件脚本 / 对话文本解析和 NPC 对话解释器（读 share/pic/EvtMrg*.Mrg、TextMrg*.mrg）
  test_evt.py            对话引擎离线自测（不需要服务端）：python3 test_evt.py
  api_map.py             通信接口覆盖表（opcode -> 方法 / 网关操作 / 页面入口）：python3 api_map.py
  web/                   页面 index.html、sprites.js、预生成的人物精灵 sprites/、roles.json、前景物件贴图 objects/（遮挡用，约 115MB）
  data/                  装备数据.csv 药品.csv 商人.csv（物品名 / 商人表）、s2t.json（简繁表，聊天用）
  share/dat/Item3.Dat    装备外观表
  share/dat/WSG*.dat     地图碰撞格（寻路用）
  share/pic/NpcMrg*.Mrg  NPC 摆放（约 2.5MB）
  share/pic/EvtMrg*.Mrg  事件脚本（约 5.7MB）  share/pic/TextMrg*.mrg  对话文本（约 7MB）
  share/pic/SceneBG*.mrg 地图背景（nomaps 版没有这部分）
  test_gateway.py        网关自测（需要网关和服务端都在运行）
  client_scenario.py     多人场景测试（聊天 / 移动 / 传送 / 换密钥）
  客户端库说明.md          协议库和网关的详细说明（含逆向结论和限制）
```

不在包里的：`loginp.exe`、登录器、服务端文件、账号记录、抓包日志。

## 8. 自测（可选）

服务端和网关都启动后，在第三个终端：

```bash
cd ~/jyclient-mac
python3 test_gateway.py --port 8088 --jyid 123456
```

最后一行 `N/N 通过` 即可（这个命令会让 123456 登录一次并说一句话；不要加 `--mutate`，那个会改角色数据）。

## 9. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页面一直"网关已连接"但登录后提示"连不上游戏服务端" | 服务端没启动，或 `SERVER` 地址不对 |
| "服务端没有回应登录（账号不存在 / 被拒 / 已在别处登录）" | 账号在服务端的角色库里不存在，或同一个号已经在别处在线（服务端强制单点登录，先让旧会话下线） |
| 地图区显示"没有找到地图 xxx 的背景图" | 该地图编号在 `SceneBG*.mrg` 里没有，或用了 nomaps 版的包 |
| 启动时有"警告：有资源没读到" | 看下面一行打印的路径，对照第 7 节检查目录是否完整 |
| 人物只有身体，没有头发 / 武器 | 见第 6 节第一条，是原版客户端的行为，不是故障 |
| 端口 8088 被占用 | `LISTEN=127.0.0.1:9000 ./start_client.sh` |
