# 网金新服务端 · macOS 部署说明

这个包是用 Python 重写的《金庸群侠传Online》服务端（`jyserver`），原版 Windows 客户端 `loginp.exe` 可以直接连。
它不需要 MySQL，也不需要原版 `服务端.exe`：角色数据在 `data/chars.sqlite`，物品 / 事件 / 商人表在 `原版数据/`。

## 1. 安装 Python 3.14

两种方式选一种：

- **官网安装包（推荐）**：到 https://www.python.org/downloads/macos/ 下载 Python 3.14 的 macOS 安装包，双击安装。
  装好后终端里用 `python3.14` 或 `python3`。
- **Homebrew**：`brew install python@3.14`

确认版本：

```bash
python3 --version
```

显示 `Python 3.14.x` 就行。如果 `python3` 还是旧版本，启动时用 `PYTHON=python3.14 ./start.sh` 指定。

新服务端只用 Python 标准库，**不用 pip 装任何东西**。

## 2. 解压

把 zip 拷到 Mac 上，双击解压（或 `unzip jyserver-mac-*.zip`），得到 `jyserver-mac/` 目录，例如放在 `~/jyserver-mac`。

打开「终端」，进入目录：

```bash
cd ~/jyserver-mac
```

## 3. 先跑一遍测试（可选，约 1~2 分钟）

```bash
python3 -m unittest discover -s tests -t .
```

最后显示 `OK` 说明在这台 Mac 上一切正常。

## 4. 启动

```bash
./start.sh
```

看到类似 `listening on 0.0.0.0:6731 (N characters in .../data/chars.sqlite)` 就是起来了。

- 第一次启动时 macOS 可能弹窗问「是否允许 Python 接受传入网络连接」，选**允许**。
- 如果提示 `Permission denied`，用 `bash start.sh`。
- 想看每个包的详细日志：`./start.sh -v`。
- 端口固定用 **6731**，因为原版客户端把端口写死了。只有自己测试时才用 `PORT=6732 ./start.sh` 换端口。
- **停止**：在这个终端窗口按 `Ctrl+C`。停止前会把在线玩家存档；平时每 60 秒也会自动存一次。

### 后台运行（关掉终端也不停）

```bash
nohup ./start.sh > server.log 2>&1 &
```

看日志：`tail -f server.log`。停止（会先存档）：

```bash
pkill -TERM -f jyserver.server
```

## 5. 让客户端连到这台 Mac

1. 查 Mac 的局域网 IP：

   ```bash
   ipconfig getifaddr en0
   ```

   有线网可能是 `en1`。也可以在「系统设置 → 网络」里看。

2. 在**玩游戏的 Windows 电脑**上，改 `客户端\maina\server.ini`，把里面的 IP 换成 Mac 的 IP。
   格式是 `名字*IP`（没有端口），文件是 **GBK 编码**，用记事本改完另存时编码选 ANSI。

3. 两台机器要在同一个局域网里，能互相 ping 通。如果 Mac 开了防火墙（系统设置 → 网络 → 防火墙），要允许 Python 的传入连接。

4. 不要再在 Windows 那边开原版 `服务端.exe` 或抓包代理：客户端只认 server.ini 里的那一个地址。

## 6. 账号管理

都在 `jyserver-mac` 目录下执行：

```bash
python3 -m jyserver.manage list
python3 -m jyserver.manage add-account 9000001 mypassword
python3 -m jyserver.manage ban 9000001
python3 -m jyserver.manage unban 9000001
```

依次是：列出所有账号和角色名；新建账号（密码只能用英文字母、数字和符号，第一次登录会进入建角色流程）；
封号；解封。

## 7. 备份

全部玩家数据就是一个文件：`data/chars.sqlite`。**停掉服务端后**把它复制一份就是完整备份：

```bash
cp data/chars.sqlite ~/chars-$(date +%Y%m%d).sqlite
```

## 8. 开机自启（可选）

把下面内容存成 `~/Library/LaunchAgents/com.jyserver.plist`，**把两处 `/Users/你的用户名/jyserver-mac` 换成实际路径**：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key><string>com.jyserver</string>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>/Users/你的用户名/jyserver-mac/start.sh</string>
    </array>
    <key>WorkingDirectory</key><string>/Users/你的用户名/jyserver-mac</string>
    <key>RunAtLoad</key><true/>
    <key>KeepAlive</key><true/>
    <key>StandardOutPath</key><string>/tmp/jyserver.log</string>
    <key>StandardErrorPath</key><string>/tmp/jyserver.log</string>
</dict>
</plist>
```

启用和停用：

```bash
launchctl load ~/Library/LaunchAgents/com.jyserver.plist
launchctl unload ~/Library/LaunchAgents/com.jyserver.plist
```

launchd 里找到的 `python3` 可能和终端里的不一样。如果日志说版本不对，在 plist 的 `ProgramArguments` 前面加上
`<key>EnvironmentVariables</key><dict><key>PYTHON</key><string>/usr/local/bin/python3.14</string></dict>`（路径用 `which python3.14` 查）。

## 9. 更新到新版本

服务端还在开发，每做完一个功能，Windows 开发机上会打一个**更新包** `jyserver-mac-update-<时间>.zip`。
更新包**不带角色库**，Mac 上的玩家数据不会被覆盖。

1. 把更新包拷到 Mac，双击解压（比如解压在「下载」里）。**不要**解压到 `jyserver-mac` 里面。
2. 终端里运行包里的 `update.sh`，后面跟安装目录（默认就是 `~/jyserver-mac`，可以不写）：

   ```bash
   bash ~/Downloads/jyserver-mac-update-20261018-1200/update.sh ~/jyserver-mac
   ```

脚本会依次：

1. 在更新包里跑一遍测试，**不通过就什么都不动**；
2. 停掉服务端（会先给在线玩家存档）；
3. 把当前的 `data/`（含 `chars.sqlite`）和旧代码备份到 `backups/<时间>/`；
4. 换上新代码；
5. 按原来的方式重新启动：原来用 launchd 的还用 launchd，原来在跑的改成后台运行（日志在 `server.log`），原来没在跑的不启动。

查看当前装的是哪个版本：`cat ~/jyserver-mac/VERSION.txt`。

- 想跳过测试（更快）：`SKIP_TESTS=1 bash .../update.sh`。
- 角色库表结构有变化时，服务端启动时会自动升级，不用手动处理。
- `原版数据/` 也会换成包里的版本。你在 Mac 上改过的 ini 在 `backups/<时间>/原版数据/` 里，要的话自己拷回来。
- `backups/` 会越积越多，确认新版本没问题后，旧的可以删掉。

**回滚**（新版本有问题时）：先停服，再把备份整个拷回来。注意角色库也会回到更新前的状态：

```bash
cd ~/jyserver-mac
pkill -TERM -f "jyserver.server"
rm -rf jyserver tests tools docs 原版数据
cp -R backups/20261018-120000/. .
./start.sh
```

把 `20261018-120000` 换成 `ls backups` 里看到的那次更新的时间。

## 10. 目前能玩什么

已实现、并且和原版逐包对照过：登录、新建角色、聊天和私聊、移动、上下线和同图玩家可见、传送、
穿脱装备、吃药、商店购买、钱庄、事件（标记 / 物品 / 数值 / 条件判断）、心跳换密钥、定时存档。

**还没有**：战斗、武功类事件、NPC 摆放、组织聊天、玩家交易等。详见 `README.md` 和 `docs/`。

## 包里有什么

| 路径 | 内容 |
|---|---|
| `start.sh` | 启动脚本 |
| `update.sh` | 更新脚本（用更新包里的那份，见第 9 节） |
| `VERSION.txt` | 打包时间，也就是版本号 |
| `backups/` | 每次更新前的备份（更新后才会出现） |
| `jyserver/` | 服务端代码 |
| `data/chars.sqlite` | 角色库（打包时的快照，含现有账号和测试号） |
| `data/` 其他文件 | 登录包模板、简繁表、默认值等，服务端运行要用 |
| `原版数据/data`、`原版数据/config` | 从原版服务端复制的 CSV 表和 ini 配置，服务端自动读这里 |
| `tests/` | 测试 |
| `tools/`、`docs/` | 开发工具和协议文档（部署不需要，留着参考）；`tools/` 里多数探针脚本是对原版服务端用的，Mac 上用不到 |

`python3 -m jyserver.importer`（从原版 MySQL 导入角色）要用原版的 `mysql.exe`，**只能在 Windows 开发机上用**，Mac 上不要运行。
