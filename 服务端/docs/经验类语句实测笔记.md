## 属:门技:N（0x6a49fb）— 已摸清，公式经实测验证
- T = (school_skill_exp + N) * 10000，转成 **32 位有符号整数（溢出按 2^32 回绕，实测：N=300000→T 回绕为负→lv0；N=429497→回绕 2704→lv19 exp234）**。
- 当前 lv(school_skill_lv) >= 100：什么 7B 都不发（只发 0x14 08「增加門技」+7D），库不变。
- T < 1：发 0x7B 49 = 原 lv、0x7B 4a = 0，库里 exp 置 0、lv 不变。
- 否则 lv<100：循环 while T > (L+1)^2: L+=1; T -= L^2。（L 为新等级。）结束后 L>100 → lv=100、exp=0；否则 lv=L、exp=T。发 7B 49 lv（LE32）、7B 4a exp、0x14 08 增加門技（最后是 7D）。
- 与是否入门派无关。注意存的 exp 是「剩余 T」，下次又 (exp+N)*10000（原版 bug，照抄）。
- 验证过的点：N=1 从 0 → lv30 exp545；N=33 → lv99 exp1650；N=34 → lv100 exp1650；lv5 exp20 N=-1 → lv82 exp2890。
- N>=~1e11 之类极端值（字符串变科学计数法）行为怪，没管。CSV 里最大 |N| = 500000。

## 属:数值夹取（现实现的 4e9 上限是错的！）
实测（N>0 / N<0 / N=0 方向性）：
- 名声/历练/杀气：N>0: min(old+N, 1,000,000)；N<=0: max(old+N, 0)。
- 学点：N>0: min(old+N, 65200)；N<=0: max(old+N,0)。
- 金钱：N>0: min(old+N, 1,000,000,000)；N<0: 新值<=0 → 整个事件中止（已有）；N=0 不变。
- 善恶（库里 evil_val，显示=evil_val-2000）：N>0: min(old+N, 3000)；N<0: max(old+N, 1000)；N=0 不动（不夹）。
- **PK值：上限 100（不是 200），无方向性：new=old+N 后无条件夹到 [0,100]**（500 −1 → 100，N=0 也夹成 100）。
- 实战：N>0 old+N 按 2^32 回绕；N<0 max(.,0)；>2^31 的值低位被舍（2048 粒度，原因没查），忽略。DB 列是有符号 int。
- 以上每种都发 0x7B <子类型> 01 + 值（LE32，善恶为有符号显示值）+ 0x14 08「…改變﹗」。
