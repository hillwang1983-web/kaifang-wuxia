# 装备与物品：穿装备 0x15、脱装备 0x16、使用物品 0x0B

方法：`tools/equip_probe.py`、`tools/use_probe.py`、`tools/multi_probe.py` 对本机原版服务端实测（克隆号 + 两个测试号），
新服务端（`jyserver/items.py`）对同样的序列逐帧输出一致：装备序列 10 步、用物品 30 次，diff 为空。
测试：`tests/test_items.py`（期望值全部来自原版回包）。

## 装备槽位

C2S 槽位号 → renwu 列：`1 toukui 头盔`、`2 xianglian 项链`、`3 yifu 衣服`、`4 pifeng 披风`、`6 wuqi 武器`、
`7 huwan 护腕`、`8 jiezhi 戒指`、`9 xiezi 鞋`。**槽位 5、0、10 以上原版不回包**（登录包 0x1E 里武器记录出现两次，
是布局上的重复，不是第 5 个槽位）。

## 穿装备 C2S 0x15：槽位(1) 物品ID(LE32) 状态(1)

| 情况 | 原版行为 |
|---|---|
| 背包里没有这件物品（含 ID=0、不存在的 ID） | **向全服在线玩家**（含自己）广播 `0x14`(长帧) 子类型 `0e` +「<名字>嘗試刷裝備﹗<物品名>」（BIG5；物品名不存在则为空）。不穿。此检查在槽位检查**之前** |
| 槽位无效，或槽位上已有装备 | 静默忽略 |
| 其余（**不检查物品类型和槽位是否匹配**，剑可以穿在鞋子位） | 写入 renwu 对应列和 `…zhuangtai`（状态字节**原样**存，状态 7 就是 7）；回 `0x17`(短) = jyid + 槽位 + 物品ID + 状态；再回 `0x7B` |

穿脱都**不改背包**：穿上的物品仍在 item 表里，数量不变。**不广播给别人**（两人同图实测，对方什么也没收到）。

## 脱装备 C2S 0x16：槽位(1)

有效槽位一律回 `0x18`(短) = jyid + 槽位（槽位本来是空的也回），列清零（id 和状态都变 0），再回 `0x7B`。

## 0x7B 属性更新（S2C 长帧）= 子类型(1) + `01` + 新值(LE32)

装备变化后，武器强度、防具强度**哪个变了发哪个**，先 `2F` 后 `30`：

- `0x2F` 武器强度 = 身上装备的「攻击」之和；`0x30` 防具强度 = 「防御」之和（装备数据.csv 第 8/9 列；
  和 0x1E 里 @274/@276 是同一个数）。例：123456 脱衣服（攻 190 防 2100）→ `2F 01 8C 05 00 00`(1420)、`30 01 86 1A 00 00`(6790)。

实测出的子类型（用物品时用到）：

| 子类型 | 含义 | renwu 列 |
|---|---|---|
| 16 / 1A / 18 / 1B | 当前 精 / 神 / 气 / 内 | dangqianjing / dangqianshen / dangqianxue / dangqiannei |
| 1E 1F 20 21 22 23 24 | 臂力 胆识 悟性 富源 定力 机敏 根骨 | str crg wint luk dex agi vit |
| 28 | 学点 | study_count |
| 2B | 实战 | combat_exp |
| 34 / 36 | 饱食 / 饮水 | diet_val / water_val |
| 3D | 名声 | fame_val |
| 44 | 历练 | exp_val |
| 2F / 30 | 武器强度 / 防具强度 | 现算，不存库 |

## 使用物品 C2S 0x0B：物品ID(LE32)（后面的字节原版不看）

- **背包里没有**（或数量用光）：回 `0x1A` = `64` +「物品不足」，`0x05`(短) = jyid + `01`，`0x14`(长) `08` +「背包沒有此物品」。
- **有，且是药品.csv 里的物品**：数量 −1（原版会存库）；按药品的效果列改角色，并为**每个非 0 的效果列**发一条 `0x7B`
  （即使值被上限截断没变也发）；顺序固定：精 → 神 → 气 → 内 → 饮水 → 饱食 → 学点 → 其余。最后回 `0x0B`(短) =
  物品ID + 耐久字节 + `01`（耐久字节取自物品表，同 0x1E 背包记录里的第 5 字节）。
  取值：精/神/气/内 加到上限（zuidajing…）为止，饮水/饱食 上限 100，其余直接累加。
- **带 max精/max神/max内 的药**（生日祝福丹、千年灵蛇丹、春雨节气大补丹）：原版**一声不吭**，什么也不回；新服务端照做，并且不消耗。
- **其余列**（永久攻/防、max气、临时攻防、状态列、特殊药、原版静默不处理的几种）：见 `docs/药品效果.md`。
