# 生活技能（伐木 / 捕魚 / 採礦）和農夫（2026-10-20）

实现：`jyserver/life.py`，产出表 `jyserver/life_items.json`（`tools/extract_life_tables.py` 从原版 `0x73c6e8` 的反编译里逐点求值抠出来）。
依据：客户端会话交接清单 + 原版反编译（`0x73645b` / `0x89229e` / `0x737bc6` / `0x73c6e8` / `0x740523` / `0x893759`）+ 实测（`tools/life_probe.py`、`life_sample.py`、`farm_sample.py`、`life_compare.py`）。
**原版不看**序号、校验字节、工具位置（F）、E / D / C；客户端会话说的「校验字节算法」对这两类指令用不上。

## C2S 0x5A（载荷 ≥ 6 字节：序号 LE32 | A | B | …）

| A | 做什么 |
|---|---|
| 1 开始（B = 1 伐木 / 2 捕魚 / 3 採礦） | 自己和**同图其他人**收 `0x82` = `jyid(LE32) 状态 00`，状态 3 / 4 / 5 |
| 3 停止（B 是 1–3） | 自己收 `0x82` = `jyid 00 00`（同图的人收不到） |
| 0 | 原版什么都不回 |
| 2 一轮 | 见下 |

一轮：

1. **精必须 ≥ 2**，否则什么都不回、什么都不变。精 −1，自己收 `0x7B 16 01 <精 LE32>`。
2. **技能经验**（`jineng` 表的 `famu / buyu / caikuang` 和 `…exp`）：经验 += **悟性 × 10**；每级要 (级+1)²（升到 L+1 扣 (L+1)²），等级到 100 清零经验、停在 100；等级已经是 100 就**什么都不变也不发 0x76**。
   回 `0x76`（短）`BE <技能号> 01 01 <等级 LE32>` 和 `BE <技能号> 02 01 <经验 LE32>`；技能号 伐木 0、捕魚 9、採礦 5、農夫 8。
3. **间隔检查**：整秒数（VB `DateDiff`）距上一次**成功**的采集 / 收成 < 4 → 自己收 `0x1A`「禁止加速採集」（原版还写日志），**到此为止**（1、2 已经发生了：被拒的轮次照样扣精、涨经验）。
4. 通过则记下时间，按**升级后**的技能等级和随机数 r（1–100）查产出表，得到物品 ID（表里没有的格子 = 物品 0）：
   - 伐木：等级 ≤ 30 恒定 44156；31–50：r ≤ 30 → 44154，31–60 → 44155，其余 44156；…（逐级见 `life_items.json`）。满级 100 才有 44169 等。
   - 捕魚：≤ 10 级恒定 44051；之后按等级段阶梯上升；61–90 级有 10% 的格子（r 31–40）什么也没有；100 级有 28197 / 28198 / 58249 这类。
   - 採礦：≤ 10 级恒定 44021；之后 44007 … 44002；100 级 44023 / 44001–44007。
   回 `0x64`（短）= `物品 ID(LE16) 01 技能号 等级(1) 经验(LE24)`（升级后的值；物品 0 也照发）。
5. **先进背包，已经有了才进钱庄**（实测）：背包里**还没有**这件物品 → 静默 +1，没有任何帧；已经有了（物品 0 总是）→ **VIP 自动存钱庄**（VIP 等级对所有人恒为 7）：背包不变，钱庄 +1（物品 0 加在 `wupin=0` 那行），和 C2S 0x22 存物品一样回 `0x0B` `0x77`（48015 的固定帧）`0x27` = `00 物品ID(LE32) 01 00 金钱(LE32) 耐久`，最后 `0x1A`「VIP功能採集物品自動存入錢庄﹗」。
   - 钱庄要有 `wupin=0` 的头行原版才会载入（建号时就有）；没有头行时存进去的东西在原版里会落到背包、下线时还会把钱庄旧行覆盖掉——这是测试库被我删过头行的假象，新服务端不模仿。
   - 实测：原版有「身上总数超过 299」的检查，我把背包总数调到 298 / 299 / 300、钱庄一件物品调到 400 都没触发，没做。
   - 原版还有「采集活动」全局开关（`DAT_00dd87d8`）和 +0x3f4 双倍经验标志，实测里都没出现，没做。

## C2S 0x5B 播種（载荷**正好 3 字节**：田块号 | 种子 ID LE16；原版看帧长字节 == 7）

- 记下「当前种子」（玩家身上一个槽，**不分田块**），自己收 `0x66` = `jyid(LE32) 田块号 种子ID(LE16) 01`；同图其他人收 `0x67` = `田块号 01`。
- 背包里有这颗种子 → 扣 1 个（不回 0B / 6B）；没有 → 再收 `0x1A`「物品不足」（前面的 0x66 照发）。

## C2S 0x5C（载荷 ≥ 6 字节：序号 LE32 | 田块号 | 动作）

- 动作 1 耕種：自己收 `0x66` = `jyid 田块号 种子ID(LE16) 03`（种子 = 上面记的那个，收成过以后是 0）+ `0x82` = `jyid 06 00`，同图其他人也收 `0x82`。
- 动作 2 收成：间隔检查同上（共用同一个「上次采集时间」）。**被拒的收成**：`0x1A`「禁止加速採集」，但照样加农夫经验（回 `0x76` ×2）、同图照样收 `0x67 田块号 00`，种子不清。通过则：
  1. 当前没有种子（没播过 / 收成过）→ 没有 `0x64`；有种子则自己收 `0x64` = `作物(LE16) 01 08 等级(1) 经验(LE32)`（**升级前**的等级 / 经验），随机数掷到 100（1%）时是失败帧 `00 00 00 08 等级 经验`、不给作物；作物进背包 +1（不发 0B / 77）。
     种子 → 作物：44201→44206、44202→44207、44203→44208、44204→44209、44205→44210、44211→44212、55001–55003→55004–55006、55028–55048→55007–55027、44218–44222→44213–44217、44226–44228→44223–44225、44229→44230（`life.CROPS`）。
  2. **29%**（随机 1–100 < 30）另外得到一件物品：自己收 `0x77` = `物品ID(LE32) 耐久 01` + `0x1A`「拿到了另外的物品」，物品进背包。候选是 0x59da85 起初始化的 20 项数组：44233、44235、44230、55701–55717（抽样 100 次收成，28 次出现，见到的 16 种都在里面）。
  3. 当前种子清空，加农夫经验（同上，技能号 8，不扣精），回 `0x76` ×2；同图其他人收 `0x67` = `田块号 00`。
