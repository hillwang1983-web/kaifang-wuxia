# 服务端功能盘点（2026-10-18）

方法：`tools/dispatch_map.py` 从 C2S 总分发函数 `0x5f8f04` 的机器码里取出「opcode → 处理函数」（opcode 取每个调用前最近的一个两位十六进制比较串，**近似**：
个别 opcode 可能差一个分支）；`tools/handler_inventory.py` 对每个处理函数扫它引用的 SQL、S2C 帧模板、中文提示（结果见下）。大小是「到下一个函数起点」的上界，
有的明显偏大（标 †）。**这里的功能名全是从提示文字和模板推测的，没有实测**，已实现的才有实测依据。
共找到 47 个独立处理函数；总分发函数里还有没挂到处理函数的 opcode（内联的小分支，如 04、05 等，没逐个看）。

## 没覆盖的

- 分发函数里还有一批没挂到处理函数的 opcode（如 04 轻频、05、以及各种两位十六进制小分支），逐个看要读汇编。
- 「找到的 47 个函数」里有的是 REA 外的工具扫出来的，边界是上界；真正做哪一个之前要先用 REA 读它的反编译。
- 所有这些都没有真客户端验证，实现时对照的只有原版服务端的行为。
