# 消点（C2S 0x5E，2026-10-20）

实现：`jyserver/study.py`，数据：`data/师傅.csv`（师傅 → 武功 / 级数 / 门派 / 地图）+ `武学系数.csv`（第 11 列 = 升级系数）。
依据：客户端会话给的交接清单 + 对原版 `0x6ef0f0`（约 3.4 万字节）的反编译 + `tools/kf_compare.py` 的 `xd-*` 场景（原版与新服务端逐帧、逐库对照）。

## 载荷与回应

C2S：`师傅 ID(LE16) 武功 ID(LE16) 点数(LE16) [序号 LE32 + 校验字节：原版都不看]`，至少 6 字节，更短静默。
S2C `0x68`（长帧）：`武功 ID(LE16) 等级(LE16) 经验(LE32) 学习点(LE16) 当前精(LE16)`，学习点是扣完以后的。

## 规则（先后顺序是实测出来的）

1. 点数 = 2 → 换成**全部学习点**（原版怪规则，没有别的含义）。点数 > 学习点 → 静默（在所有检查之前）。
2. **基本武学**（8001–8015、8017；55555 当 8017）：**不看师傅、地图、门派**；等级 / 经验存在 renwu 里（`daofa` … `dushushizi` 和 `…exp`），不在 kf 表。其余走第 3 步。
3. 普通武功（`武功 ID` 不是上面那些）：
   1. 师傅表里没有 (师傅, 武功) 这一行 → 自己收 `0x14 03` 「無此師傅代碼，請聯系GM告知此代碼<师傅>﹔<武功>」，**全服**收 `0x14 0e` <名字>「請聯系GM告知此代碼:<师傅>﹔<武功>」。
   2. 玩家**没有**这门武功（kf 表里没有这一行；等级 0 的删除残留算有）→ 全服 `0x14 0e` <名字>「嘗試刷武功:<武功>」，到此为止（不管地图、门派对不对）。
   3. 这一行「门派」≠ 0 且 ≠ 玩家门派（**先于地图检查**）→ 先随机掉一级，**然后**全服 `0x14 0e` <名字>「嘗試刷不屬于自己門派的武功﹗<武功>武功隨机掉一級」。
   4. 玩家当前地图 ≠ 这一行的地图 → 全服 `0x14 0e` <名字>「消點地圖不正确!:<武功>武功隨机掉一級」，**然后**随机一门武功掉一级（见下）。
4. 随机掉一级：玩家**至少有 2 门**武功才会掉（只有 1 门从不掉；实测 60 次 × 2 / 4 / 8 门，每次必挑中一个，大致均匀）。在全部武功行里随机挑一个；转生武功 3860 和等级 ≤ 1 的挑中了就什么都不发，否则等级 −1，自己收 `0x70`（长帧）= `学习点 精 武功 新等级 经验(LE32)`。
5. 点数 = 0 → 回显一条 `0x68`（不变）。
6. 经验：`int(点数 × min(悟性, 100) × 1.5)`（取整数部分，不是四舍五入）。
7. 升级：循环「经验 − 升级门槛 > 0 就升一级、扣掉门槛」，门槛 = `int(系数 × (等级+1)³)`，系数是**单精度**（`武学系数.csv` 第 11 列：1014 → 2，1005 → 1.2，8006 → 5，8017 → 1.5，其余基本武学 1）。
   - 等级上限：普通武功 = 师傅表的「级数」，基本武学 150（读书识字 100）。循环是 do-while：升到**超过**上限就停，先发 `0x1A`「超過消點等級」，等级改回上限，剩下的经验照留；等级本来就超过上限而经验不够升级的，不动、不提示。
   - 落库：普通武功写 kf 行的 `kf_lvl / kf_exp`，基本武学写 renwu 列，`study_count` 扣点数。
8. 副作用（**不发 0x7B 以外的东西**，库里下线时落）：
   - 基本内功（8006）：每升一级，精 / 神 / 气上限各 +400、内上限 +5；`0x68` 之后**不管有没有升级**都发 4 条 `0x7B`：`15`（精上限）、`17`（气上限）、`19`（神上限）、`1C`（内上限）。
   - 搏击格斗（8012）/ 闪躲纵跃（8013）/ 读书识字（8017）：每跨过一个十级，臂力 / 机敏 / 悟性 +1，发一条 `0x7B`（`1E` / `23` / `20`，显示值最大 100，库里不封顶）。

## 没做 / 不确定

- 随机掉级的挑选范围是否包含基本武学：实测只在 kf 表里挑。
- 8016 在原版里没有分支，这里当作不存在（普通武功路径，查不到师傅就报「無此師傅代碼」）。
- 原版收到校验错的包（`校验字节`）的行为没测——它根本不看这个字节。
