# UI 设计图

策划把界面设计图放在这里，开发按图实现。

本阶段要出的全部图（场景、角色、Boss、特效、头像、界面）和交付进度见 [交换清单_第一里程碑.md](交换清单_第一里程碑.md)；规格以 `参考资料/武侠 ARPG 美术说明（AI 生图用）` 为准。

## 放图约定

- 格式：PNG / JPG（Figma、PS 等导出即可）；有源文件可以一起放。
- 命名：`序号_界面名.png`，例如 `01_开始与门派选择.png`；同一界面多个版本加后缀 `_v2`。
- 尺寸：按美术说明的内部分辨率 960×540 出图（整数倍放大到 1920×1080）。试玩走网页版，手机横屏和电脑浏览器都要能玩；手机上画面整数倍放大、左右留黑边，按键要能用拇指按到。
- 标注：按钮的按下 / 冷却 / 不可用状态、字号、颜色值、留白，能标就标；没标的部分开发按美术说明第八节「墨底金边」或交换清单第九节定下的底色来做。
- 图标、头像等单独切图可放 `切图/` 子目录。

## 第一个里程碑需要的界面

对应小说节点 0–3（茶棚 → 破山门 → 叛僧教头）和双人合击。

1. **开始界面与门派选择**：少林 / 邪派二选一，各自一句定位说明。
2. **进副本前通用技三选一**：梯云纵、运功疗伤、截脉。
3. **战斗主界面（HUD）**
   - 自己的血、内力、身法。
   - 左上：队友（净心）血条与默契值（含一 / 二 / 三级的显示）。
   - 顶部：Boss 血条，下方是读条。
   - 按键：普攻、三个主动、通用技、合击、闪避；技能图标本身显示冷却（变暗 + 顺时针扫过）。
   - 键鼠与手柄的键位提示（手柄图标按 Xbox / PS 切换）；手机：左侧摇杆，右侧按键群（第一里程碑就要）。
4. **三种释放机制的指示器**：点按（无）、蓄力（蓄力进度）、拖动瞄准（方向 / 落点）。
5. **合击**：发起时地面光圈、队友看到的邀请提示（屏幕中央偏下，光圈 + 三秒倒计时）、成立瞬间的定格与两人剪影（≤0.5 秒）。
6. **对话框**：带头像，对应净心、玄诚。
7. **任务提示 / 目标**与**暂停菜单**。

## 之后里程碑才需要（可以先不出）

物品栏（10×6 格）与装备栏、掉落与通关箱、三人阵法、弩车操作界面、出身选择、队伍界面。
