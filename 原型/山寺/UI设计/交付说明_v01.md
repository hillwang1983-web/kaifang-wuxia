# 第一里程碑 UI 交付 v01

日期：2026-10-24。风格采用用户确认的「墨底金边」。依据交换清单第九节最新六项定案与第一里程碑触屏要求制作。

## 本批内容

- 16 张 960×540 效果图，以及各自的 1920×1080 最近邻 2 倍预览。
- 52 张独立游戏资产：13 枚图标、4 张 96×96 对话头像、2 张门派选择插图、32 张 UI 框体/状态/触控/指示器，以及 1 张合击成立定格。
- 设计目录 `切图/` 中有与游戏资产逐字节一致的副本。
- `交付清单_v01.json` 逐文件列出尺寸与 SHA256；`布局参数_v01.json` 列出位置、颜色、字号和安全区。

主效果图为 `01_开始界面`、`02_门派选择`、`03_通用技选择`、`04_战斗HUD`、`05_任务与暂停`。补充手机 HUD、安全区、Xbox/PS 提示、净心/玄诚对话、释放机制、按钮/默契状态、合击成立、图标总览与任务气泡。

## 六项定案的应用

1. 面板 `#15121A`，87% 不透明度；原生 1px `#FFD24A` 金边。
2. 门派选择与 HUD 玩家预览统一用束发布巾的普通青年头，不绑定四出身。此处的 48×64 单帧仅是 UI 比例参考；玩家全套动画未作为本批交付。
3. 邪派选择图为宽背薄刃单刀，不画日本刀。
4. HUD 的玄诚重击用黄色读条与「重击蓄力」提示；本批不改变其游戏动作实现。
5. 净心头像按十七岁清瘦少年僧绘制，包含 `normal` 和 `sad`；玄诚包含 `cold` 和 `smile`。
6. 保留「金刚伏魔圈」名称，本批未另拟替代名称。

## 程序接入

- 游戏资产放 `../assets/ui/`、`../assets/ico/`、`../assets/por/`、`../assets/vfx/`。设计效果图、对比图和源文件留在本目录，不作为整屏运行贴图导入。
- UI 框、图标、触控底座不带文字、人名、数值或冷却数字；文字由程序用已接入的 Fusion Pixel 字体渲染。效果图字体为 12/24/36px。
- 血/内力/身法/读条填充为独立 1×1 颜色纹理，程序依据数值拉伸到槽内；金边保持最近邻整数像素。
- `ui_button_*` 的边角可按 4px 九宫格边距处理。带状态槽的组合框按布局 JSON 定位内部槽，不单独拉伸文字。
- `ui_skill_cooldown_v01.png` 是 60% 左右的顺时针遮罩样式示例，不应作为固定冷却结果。运行时按实际剩余比例绘制扇形/TextureProgressBar，并单独排倒计时文字。
- 普通/按下/不可用底座与技能正常图分层；不可用状态应根据消耗/控制状态计算。效果图中的血量、冷却和键位仅供排版，不修改策划数值或工程 InputMap。
- Xbox/PS 两张图展示提示切换；最终绑定以工程输入映射为准。
- 手机摇杆底座 128×128、摇杆头 56×56；右侧技能至少 64×64，普攻示意 80×80。两排按钮的图形边界互不重叠。左右最小安全区为 24px，接入时取设计值与设备实际安全区的较大者；整数倍放大后多余空间留黑。
- 合击邀请背景与倒计时弧单独提供；三秒倒计时、闪烁和渐隐由程序控制。`vfx_heji_freeze_v01.png` 为三色全屏单帧，显示不超过 0.5 秒。
- 对话框 928×132，头像位 96×96；示例台词用于排版，实际剧情以小说/程序为准。

## 源文件与验证

`源文件/` 包含内置 image_gen 的原图、提示词、字体与许可，以及使用 Node.js 和 ImageMagick 的单用途排版脚本。进入该目录运行 `node build_delivery.mjs` 会在 `delivery/` 重新输出素材；无需调用生图 API。

已核对尺寸、透明通道、图标/头像色数、命名、切图副本一致性及整数放大效果。电脑/手机图是静态设计交付，尚不等于 Godot 实际接入或实体手机触控验收。

交接清单本批标记为「已交」；「已入库」由开发导入并核对后填写。
