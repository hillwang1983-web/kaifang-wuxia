# 美术 ↔ 开发 交换清单：第一里程碑

这是美术和开发之间的交换文件。美术每交一张图，就在对应行填「状态 / 日期 / 文件」；开发入库或发现问题，在「开发回执」里回话。清单本身就是进度表。

- **依据**：`参考资料/武侠 ARPG 美术说明（AI 生图用）`（下称「美术说明」）的规格、调色板、命名和校对清单，《垂直切片功能规格书》，小说《山寺归僧》。
- **本阶段范围**：小说任务节点 0–3。茶棚遇见净心看血书 → 破山门（熄火把、清喽啰）→ 叛僧教头玄诚两阶段（教闪避、教打断）→ 玄诚坐地交代。主角带 AI 净心，少林、邪派两门派都能选，双人合击和默契值上线。
- **不在本阶段**：藏经阁、毒姥、大雄宝殿、铁甲金刚、弩车、阵法；四种出身的场景、头像、叠层；现代车间；装备图标、物品栏、通关箱。美术说明第十节里这些排在后面周次的资产，先不出。

## 交付约定

- **游戏用资产**放 `原型/山寺/assets/`，按前缀分子目录：`env/ chr/ npc/ boss/ vfx/ ico/ ui/ por/ ref/`。旧版本移进同目录的 `old/`，不要删。
- **界面设计图（效果图）**放本目录 `UI设计/`，命名 `序号_界面名_v01.png`，切图放 `UI设计/切图/`。
- **命名**沿用美术说明第九节：`前缀_名称_动作_帧号_v版本.png`，全小写、下划线，版本两位从 v01 起。开发只导入最高版本。
- **背景**：角色、特效、图标最好直接给透明 PNG；GPT 只能出品红 `#FF00FF` 底也行，开发入库前批量抠成透明（Godot 运行时不抠色）。
- **引擎**：切片用 Godot 4.7。图放进 `assets/` 后 Godot 自动导入，工程已设最近邻过滤，不用另调。美术说明第七节的点光源与法线贴图 Godot 都支持；法线贴图由开发用工具批量生成，本阶段美术不用出。
- **尺寸**：交缩好的目标尺寸（Aseprite 最近邻缩小、修过线），不要交 GPT 原图。原图要留可以放 `ref/`。
- **方向**：角色出正面、左侧、背面三个方向，右侧由程序镜像。
- **动画帧**：横排成一条（等距、等大画布），或者每帧一张都行。一条动作一个文件，如 `chr_shaolin_walk_left_v01.png`。
- 每张图入库前先过美术说明第九节的「入库前校对清单」。

状态写法：`未开始` / `出图中` / `已交` / `已入库` / `退回`（退回原因写在开发回执里）。

## 九、待拍板（美术开工前定）

1. **界面底色**：美术说明是「墨底金边」（墨黑 `#15121A` 半透明底 + 1 px 内力金边）；V0.4 松风 clear1 是「深绿底金边」（`#1b362a` 一类）。你之前说沿用 V0.4 的 UI，两者选哪个？
2. **玩家临时头**：本阶段没有出身，第 11 条先出一个通用青年头可以吗？还是直接用四出身里的某一个（比如铁匠之子）？
3. **邪派默认武器**：少林是棍；邪派招式都是掌和毒，普攻拿什么？建议用刀，和喽啰同类，省一套武器画法。
4. **玄诚重击的起手**：美术说明写的是「双手举棍过头、脚下开裂纹」，小说第三章写的是「双掌合十，气聚胸口」，被净心一棍点在手上打断。动画按哪个？
5. **净心年龄**：美术说明写「十来岁」；小说设定表写十四岁，但按第二章的时间线下山时是十七岁。体型差别不小，先定再画。
6. **「金刚伏魔圈」改名**：这是《倚天屠龙记》里的阵名，美术说明里默契三级和阵法都用了它，和「不出现金庸元素」的要求冲突。本阶段默契三级特效要用，先定新名字（只影响文件名和台词）。
