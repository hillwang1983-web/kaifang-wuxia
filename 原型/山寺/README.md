# 山寺（垂直切片，Godot 4）

把 `参考资料/` 里《武侠 ARPG 垂直切片功能规格书》、小说《山寺归僧》和《美术说明（AI 生图用）》做成可玩的垂直切片。2026-10-23 决定用 **Godot 4.7** 做，不再沿用网页原型的代码；`原型/V0.4/`《青石渡风波》本身不改。

当前状态（2026-10-24，**功能阶段 A–F 已做完，转入按试玩反馈修改**）：开始界面 → 选出身 → 选门派 → 出身开场（节点 0）→ 选通用技 → 山门熄火把、击退喽啰（节点 1）→ 玄诚两阶段（节点 2–3）→ 后院回廊 → 藏经阁毒姥与三人阵法（节点 4–5）→ 寺后院子 → 大雄宝殿弩车与铁甲金刚（节点 6–7）→ 通关箱 → 三段合并结算 → 回开始界面。

- **联机未做**（用户 2026-10-24 拍板：联机先不做）。规格书要求的两到四人联机、服务端权威、一百五十毫秒延迟验收都没有做；但 sim 层已按服务端权威拆好：全部战斗规则、合击 / 阵法、弩车、掉落都在不依赖场景树的 `scripts/sim/`，每帧只吃各英雄的 `SimCommand`，世界状态只由 sim 改、画面只读；队友 AI 和真人走同一个指令接口。接联机时由 Godot 无头服务端跑这一层、客户端只发指令收状态。
- **美术**：界面、图标、头像、合击定格与光圈、茶棚与山门场景已是美术交付；人物里少林玩家（待机 / 行走）、净心与韩青（全套）、玄诚（待机 / 行走）已经接上帧动画，其余动作与角色、藏经阁 / 大雄宝殿 / 开场四间屋子、毒姥、铁甲金刚、弩车与大部分招式特效仍是代码画的占位（清单见交换清单与 [`试玩/收尾清单.md`](试玩/收尾清单.md)）。
- **音效**全部是程序合成的占位（见下「表现层」），没有外部音频文件。

- **出身与开场**（规格书第九节、第十节第八到十周）：开局四选一——富家子弟（沈家少爷，重线）、铁匠之子（重线）、戏班小旦（轻线，默认「玉儿」，选择时可改名）、游方郎中小徒弟（轻线）；出身和门派分开选、互不绑定，出身不改任何战斗数值（铁匠之子起始武器是锤子，锤子没有属性、不进任何掉落），存档记住出身和名字，结算显示出身。
  - 开场（`prologue.gd`，四条共用一个关卡）：现代车间十秒（四条共用）→ 白光、附身醒来 → 该出身的屋子（沈家卧房、铁匠铺、茶馆后台占位；郎中线就是原来的茶棚，净心从开场就在）→ 教学三项由在场 NPC 引导（走到发光处、打碎道具、躲开 NPC 比划的一下——伤害为 0）→ 交互拿到线索（血书 / 朱砂圈图纸 / 裹纸条的银子 / 阿萝的黑舌）→ 出门。暂停菜单里可「跳过开场」。
  - 三处分叉：开场演出；进寺方式（山门前出生点、门前的人和对话按出身不同，进了门洞合流；邪派多一句「奉命入寺夺取秘籍，却发现叛僧另有图谋」）；Boss 一收尾（玄诚交代完后按出身各一段：赎罪 / 报仇 / 查纸条 / 治病）。
  - **全部台词在 `data/story.json`**（标「草稿」，Mark 直接替换）：开场每条 160–255 字（上限 500），收尾每段 ≤ 42 字（上限 100），副本内共用 646 字（上限 800），测试会查字数。规格书说开场依据小说第二标签页「四个开头」，本机的小说只有第一页，开场是按规格书出身表改写的草稿。
  - 代玩四条出身从开场到山门 19–22 秒（游戏时间；代玩不读台词、对话自动翻页，真人要多算读字的时间），规格书要求五分钟内。
- **表现层**（规格书第三、四、五节，阶段 F）：
  - 角色帧动画（`sprite_lib.gd` + `data/anim.json`）：按「前缀_动作_方向_v版本.png」读美术交的动作条，按状态挑动作（待机、行走、普攻、受击、翻滚、倒地、招式），按朝向挑方向（右侧镜像左侧），按脚底锚点对位；缺的动作按登记的替代链回落（如少林普攻没交时用待机），整个角色没图就画代码占位。美术以后交新动作只要放文件，新角色在 `anim.json` 加一行。
  - 音效（`sfx.gd`）：每招（两门派三主动、三通用技、两种普攻）、合击、阵法、打断、三个 Boss 的主要招式、弩车、拾取等都有各自的声音，全部由程序用正弦 / 方波 / 锯齿 / 噪声合成（自制，无第三方版权）；背景是程序合成的低频持续音。三条总线：音乐、音效、界面，暂停菜单里各有滑条，存在存档的 `settings` 里。正式音效以后按 `Sfx.RECIPES` 的键名换成文件即可。
  - 特效：每招有自己的特效（截脉的指劲、毒砂掌出手、阵法的金色三角阵与莲纹、横扫弧光、冲撞尘土、毒蛊落点等）；命中闪白、顿帧、屏幕震动（暂停菜单可关）。
  - 合击引导（第四节硬指标）：邀请时光圈闪烁、提示音、屏幕中央下方倒计时；AI 发的前两次邀请加强引导——从玩家脚下到光圈一道流动金光、光圈外一圈呼吸光、提示音每秒再响直到响应、净心自己站进光圈示范。暂停菜单「本局关闭合击提示」（接口是世界的 `combo.muted`，只关提示不关合击）。
  - 界面按第五节：技能图标即冷却（变暗 + 顺时针扫）、蓄力进度在指示器上、队友血条与默契在左上、Boss 血条在顶部、读条在其下；按键提示跟最近用的设备切换：键鼠 / Xbox（A X Y B、LB RB RT）/ PS（× □ △ ○、L1 R1 R2），手柄名里带 PlayStation / DualSense / DualShock 认作 PS。
- **平衡**（阶段 F）：`tools/balance.gd` 批量代玩三个 Boss × 两门派 × 三通用技 × 多种子 × 两种玩家水平，结果在 [`试玩/平衡_代玩统计.md`](试玩/平衡_代玩统计.md)，结论与建议在 [`试玩/平衡建议.md`](试玩/平衡建议.md)：模拟新手首通玄诚 50%、毒姥 33%、铁甲金刚 33%。三个 Boss「不闪避 / 不摆阵 / 不用弩车必团灭」写成了测试（毒姥加了毒雾收口、铁甲金刚 240 秒狂暴）。
- **试玩表格**：[`试玩/手感评分表_模板.md`](试玩/手感评分表_模板.md)（每技能手感、每 Boss 挫败感、合击爽感、Bug 数、最想砍的一样）、[`试玩/外测记录表_模板.md`](试玩/外测记录表_模板.md)（出身、首通是否成功、第一次自发合击用时、能否说出「我是谁、为什么进寺」）。
- **山门**（1920×1080，横纵各两屏）：镜头跟随玩家、朝瞄准方向略提前、不出地图边。下半石阶前庭熄火把、清喽啰，穿过门洞进上半操练场触发玄诚，进场后门洞在身后合上（操练场锁边界）。石狮、香炉、树丛有碰撞；人物被门檐挡住时在上面补一层半透明剪影。
- **寻路**：AI（净心、代玩）能直走就直走，看不见目标就经门洞路点绕行，贴着障碍会左右偏转；敌人追击同样走这套。

## 第一里程碑做了什么

- **两门派**：少林（罗汉拳点按三连、金钟罩蓄力护盾、大力金刚掌拖动瞄准扇形击退；被动受击积内力，满了下一招带硬直）；邪派（毒砂掌点按飞掌、化功散拖动落点毒池减速、摄魂术蓄力射线，蓄满定身；被动叠毒三层引爆）。普攻三连、按住连击、闪避耗身法带无敌帧，沿用 V0.4 手感。
- **通用技三选一**：梯云纵（短距闪现）、运功疗伤（自疗，身边队友回血渡气）、截脉（打断读条）。
- **合击与默契**（规格书第四节）：按住合击键摆光圈、松开发邀请，三秒内队友按合击键或走进光圈即成立；全屏定格 0.45 秒后光圈内敌人吃伤害、读条被打断并失衡；没人响应就退化为门派招式（不耗内力、不进合击冷却），默契归零。默契按局计算、分三级，三十秒内连续成功额外加一。
- **AI 净心**：和玩家一样只产出操作指令（「搭档接口」）。会跟随、普攻、看红区闪避；玩家发邀请时走进光圈；玄诚读条时自己发邀请等玩家响应，不替玩家包办打断。
- **玄诚**：带架势（普攻只吃一半），预警末段闪过横扫或被打断会失衡 2 秒（吃满伤害）。半血进入阶段二，加入 2 秒读条的重击，不打断就全场重伤 350。血量归零坐地，不死。
- **败退**：玩家倒下两秒后两人回山门口重来（打玄诚时他也回满血）；净心倒下八秒后自己爬起来。
- **后殿藏经阁与 Boss 二毒姥**（规格书第四、六、九节）：玄诚交代完接后院回廊（三名喽啰、木箱酒坛，打碎掉金钱丹药，留了弩车零件接口），穿门洞进藏经阁。藏经阁是代码拼的占位场景（美术已列在交换清单第 60–64 条）。进阁时第三人「韩青」加入（用户拍板：临时 AI 侠客，和净心同一套 AI；配置在 `SimData.PARTY`），三人阵法启用，大厅锁边界。
  - 毒姥机制全在 sim 层：毒罩常驻减伤 95%；开战 10 秒后毒雾从四边往里压（雾中每秒掉 3% 生命），毒罩碎时暂停；毒蛊每 5 秒点一人脚下，0.8 秒红区后留 15 秒毒池；摄魂指每 12 秒读条 1.5 秒（不能打断，读条在 Boss 血条下方），点名定身 3 秒，自己或队友的截脉能解。
  - 三人阵法「金刚伏魔圈」：和合击同一流程，要两名响应者进圈；成立后震碎毒罩 10 秒、圈内净化毒雾，16 秒后才能再摆；只等到一人退化为双人合击（破罩 5 秒），一人没等到退化为门派招式。合击、阵法共用默契等级与反馈，阵法定格先用合击定格。
  - 毒姥倒下后离场，阿萝脱险、一年之约用字幕播（不挡操作），毒姥必掉一件防具；捡起来、字幕播完进大雄宝殿。毒姥血量 5500 是草稿，三个满操作 AI 约四轮破罩。
- **大雄宝殿、弩车与 Boss 三铁甲金刚**（规格书第六、七、八、九节，小说第五章）：藏经阁之后经寺后院子（过渡段）进大殿，大殿锁边界、金刚醒来。场景是代码拼的占位（美术已列在交换清单第 65–70 条）。
  - 弩车全在 sim 层（`sim_ballista.gd`，状态只在 `SimWorld.ballista / parts / pile_parts`，为联机一致预留）：殿内两侧四个零件堆，三个各掉一样零件（底盘 / 弓臂 / 绞盘）；走过去自动背上（每人一格零件位，不进物品栏），带到殿中央自动装上；三样齐了在中央按交谈键拼装，读条 3 秒，走动、闪避、出手、挨打、被抓都会打断。拼好后按交谈键上车（不能走动），再按下车，车上按闪避是跳车翻滚；按住普攻蓄力、松开发射，三档（0.5 秒、1.1 秒分档），瞄准用鼠标 / 右摇杆 / 拖技能键，不给就自动瞄金刚。弩车耐久 3：被冲撞或被扔过来的人砸中扣 1，扣完散架、三样零件随机散到殿边，捡回来再拼。任何人都能拼、能坐；真人走过来要坐时 AI 会让座。
  - 铁甲金刚：非裂口伤害减免 99%；弩箭在命中点留裂口（三档大小 10 / 16 / 24，持续 20 秒，最多同时三道），命中点落在裂口上的伤害吃满——所以要从裂口那一侧打。不吃打断、硬直、定身。每 25 秒冲撞一次（首次 15 秒），朝弩车（没拼好就朝人）预警 2.5 秒，预警期间合击 / 阵法成立就撞偏、失衡 3 秒；踏地震全场 0.8 秒预警，翻滚 / 梯云纵的无敌时间能躲；抓最近的非操弩者往弩车扔，砸中扣耐久。血量 10000 是草稿，三个满操作 AI 约 72 秒、撞偏两三次。
  - AI：第三人韩青负责捡零件、打零件堆、送零件；零件齐了谁空着谁拼；净心在车空着时上车打四发满档再让出来（真人走近就让座）；金刚预警冲撞时 AI 发阵法邀请等大家来撞偏（只靠两个 AI 凑不齐两名响应者，要玩家响应）；没有裂口时不去硬砍铁甲，把金刚往远离弩车的方向引。
  - 金刚跪倒后「痛快」字幕，殿中央出现通关箱：每个有物品栏的人开一次各得一件，底子在八种里随机，品质魔法六成、稀有四成；金刚另掉一件饰品底子。都捡完后净心说一句收尾（一年之约的悬念），然后三段合并结算（山门 / 藏经阁 / 大雄宝殿各自用时、合击、阵法、打断 / 破罩 / 撞偏次数与所获，加总计），回开始界面。
- **装备掉落与物品栏**（规格书第七节）：物品 = 底子 + 品质 + 词缀，数值全在 `data/items.json`（八种底子、普通 / 魔法 / 稀有 5:4:1、十二条词缀各三档、掉落表）。喽啰掉金钱和丹药，玄诚坐地后必掉一件武器底子，走过去自动拾取（或按交谈键）；掉落用单独一路随机数，同种子可复现。10×6 格子物品栏 + 兵器 / 防具 / 饰品两格装备栏，鼠标拖拽（右键快捷装备 / 服用）、手机拖拽或点选后按按钮、手柄 / 键盘光标都能操作；Tab / Start / 手机右上「囊」打开，打开时战斗暂停。装备后攻击、攻速、暴击、生命、内力、回复、移速、毒伤、护盾、合击伤害、默契获取都真正生效；丹药 H / 十字键下快捷服用（回 300，冷却 5 秒）。图标与面板是占位，美术已列在交换清单第 56–58 条。
- **武功熟练度壳**（规格书第三节）：物品栏「武学」页选一门参悟，每 5 秒熟练度 +1，一次只参悟一门；只存储和显示，不影响战斗。
- **存档**：物品栏、装备、金钱、熟练度存在 `user://shansi_save.json`（网页上是浏览器本地存储），刷新后还在，重开一局也带着；留了 `version` 与 `runs` 字段给以后多局。开始界面可「清空存档」（按两次确认）。
- **操作**：键鼠、手柄、手机触屏（左摇杆 + 右侧按键群，拖动技能键瞄准，支持多点同时按；身边有火把或能说话的人时多出一个「交谈」键）。

## 打开与测试

Godot 4.7.2 用 winget 装（不需要管理员；没有 `godot` 短命令，可执行文件是 `Godot_v4.7.2-stable_win64_console.exe`，安装时已加进用户 PATH，新开终端生效）：

```bash
winget install --id GodotEngine.GodotEngine --exact
```

打开 Godot → 导入 → 选本目录的 `project.godot`；F5 运行。

无界面测试（先导入资源，再跑 `tests/test_*.gd` 的规则用例，最后让 AI 代玩做冒烟——四条出身各走到山门并计时、跳过开场一次、按日期轮换一条出身跑全程；任何一项失败或脚本报错，退出码为 1）：

```bash
powershell -ExecutionPolicy Bypass -File 原型/山寺/tools/test.ps1
```

CI：改动本目录的 PR 和推到 main 的提交会触发 `.github/workflows/shansi.yml`，在 Linux 上用 Godot 4.7.2 跑同样的导入、规则用例和 AI 冒烟（日志里出现 `SCRIPT ERROR` / `ERROR:` 也算失败）。全新检出没有字体缓存，首次导入会临时清空 `theme/custom`，导入后恢复，做法与 `scripts/build-shansi-preview.mjs` 相同。CI 不做网页导出，也不代替实体手机与手柄验收。

开发开关：命令行 `Godot_v4.7.2-stable_win64_console.exe --path 原型/山寺 -- skip auto quit xiepai yungong`，网页地址加 `?skip&auto`。`skip` 直接进山门；`auto` 由 AI 代玩、自动翻对话，从出身开场一路打到大雄宝殿结算（命令行四倍速）；`quit` 打完退出并打印结算；`xiepai`、`tiyunzong` / `yungong` / `jiemai` 指定门派和通用技；`mobile` 电脑上强制手机界面；`items` 用单独的演示存档塞几件样品看物品栏；`torch` 山门出生在火把旁；`fresh` 先清空存档；`origin=shenjia|tiejiang|xiban|langzhong` 指定出身（代玩默认郎中）；`skipintro` 开场一开始就走「跳过开场」；`until=shanmen` 走到山门就打印代玩计时并退出；`fps` 每 5 秒打印平均 / 最低帧率；`pad=xbox|ps` 没插手柄也显示手柄按键提示；`boss2` 直接进藏经阁；`boss3` 直接进大雄宝殿；`shots=10,20` 按真实秒数存画面到 `user://shot_*.png`（要原生窗口运行，存完退出），也可以写事件名 `shots=aim,deflect`（大雄宝殿里有人满档蓄力瞄准、冲撞被撞偏时各拍一张）。代玩用单独的测试存档，不碰真存档。

工程设置：内部分辨率 960×540、窗口 1920×1080、整数倍拉伸（手机上改为非整数等比缩放，见下文），贴图默认最近邻、2D 变换吸附整像素（像素风不糊）；渲染器用 Compatibility（网页导出走 WebGL2）。

## 试玩：网页版（手机与电脑浏览器）

试玩发链接、浏览器打开，不发 exe。导出网页版到 `build/web/`（已被 `.gitignore` 排除）：

```bash
powershell -ExecutionPolicy Bypass -File 原型/山寺/tools/export_web.ps1
```

本机预览用 `.claude/launch.json` 的 `shansi-web` 配置（`python -m http.server 8772 --directory 原型/山寺/build/web`，只听 127.0.0.1）。

- 导出用单线程版本（`variant/thread_support=false`），不需要 COOP / COEP 响应头，iPhone Safari 也能跑。
- **PWA 已关闭**（2026-10-24）：开着时 Service Worker 会一直拿最早缓存的 `index.pck`，部署新版后试玩的人还在玩旧版。试玩期先关；「添加到主屏幕」全屏等版本稳定后再开，届时要先解决缓存更新。
- 体积（2026-10-24 阶段 F 构建，含全部关卡与已入库美术）：`index.wasm` 38.6 MB（引擎本体；gzip 后约 10.0 MB）、`index.pck` 4.1 MB（游戏内容，图片已压缩，gzip 几乎不再变小）、`index.js` 0.27 MB（gzip 0.07 MB）。服务器开 gzip 时手机首次加载约 14 MB；之后浏览器缓存。**发布包自带的静态服务（`app/server.mjs`）不压缩**，2026-10-24 本机核对 `index.wasm` 是 38.6 MB 原样下发；要在看板网关或反向代理上开 gzip / brotli，否则手机首次要下 43 MB。
- 发布流程（#24 的 `npm run build:shansi`）2026-10-24 用提交 ab90632 核对过：导入、全部规则测试、`auto quit` 通关（37 秒，脚本限时 180 秒）、网页导出、打包与 `runtime-manifest.json`、本地起服务按清单核对哈希都通过。在 Windows 上脚本的第一步解 git 归档会失败（Git Bash 的 tar 把 `C:` 当主机名、系统 tar 不认中文文件名），是开发机环境问题；发布机（macOS / Linux）不受影响。
- 帧率（原生窗口模拟，不是实体手机）：在 844×390（iPhone 横屏尺寸）、800×360（中档安卓横屏尺寸）、960×540 下打铁甲金刚（最满的一场），关掉垂直同步时每帧 CPU 约 0.3–0.5 毫秒画面 + 0.35 毫秒界面 + 0.02 毫秒世界，帧率 600 以上；开垂直同步时这台开发机窗口模式固定在 30 帧左右（显示器 / 合成器的限制，与游戏负载无关）。手机浏览器里 GDScript 慢得多，估计每帧仍在几毫秒以内，**实体手机没测**，第一次在手机上打开时请在网址后加 `?fps` 看控制台帧率。
- 画面按设备实际像素整数倍放大（布局参数的约定）：iPhone 横屏（DPR 3）放大 2 倍，左右留黑边。**小屏安卓（如 740×360、DPR 2）只能放大 1 倍，画面只占屏幕约三分之二、12 像素字偏小**——已按 #25 改为：手机（网页版安卓 / iOS 与原生移动端）在启动时切到非整数等比缩放铺满可用区域，保持比例、只留宽高比差异带来的少量黑边；电脑仍是整数倍，像素清晰。代价是手机上像素宽度不完全均匀。
- 网页里没有系统中文字体可回落，界面字体用工程自带的 Fusion Pixel 12px 简体（`assets/fonts/fusion-pixel/`，SIL OFL 1.1，许可文件同目录），主题在 `scenes/default_theme.tres`，字号按 12 的整数倍用。
- 公网接入与 macOS 构建见根目录 `docs/山寺公网发布.md`；青石渡仍使用独立入口。
- 导出模板 4.7.2 已装在 `%APPDATA%\Godot\export_templates\4.7.2.stable\`（含 Windows，以后要出 exe 也能直接导）。

## 键位

由 `tools/setup_input.gd` 生成进 `project.godot`，改键位改这个脚本再跑一遍（命令见脚本头注释）。

| 动作 | 键鼠 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准 | 鼠标位置（两秒不动就改回自动瞄准） | 右摇杆 |
| 普攻（按住连击） | J / 鼠标左键 | A |
| 主动一 / 二 / 三 | U / I / O | X / Y / B |
| 通用技 | K | RB |
| 合击 | F | RT |
| 闪避 | 空格 | LB |
| 取消蓄力 / 瞄准 / 光圈 | Esc / 鼠标右键 | LT |
| 交谈 / 互动 | E | 十字键上 |
| 物品栏（打开时暂停） | Tab | Start |
| 丹药 | H | 十字键下 |
