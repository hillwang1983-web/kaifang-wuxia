# 松风场景图集

`world-atlas.png`：2026-10-23 使用内置 imagegen，为《开放武侠》独立 V0.4 松风版生成的原创场景素材图集。1024×1536 RGBA，24 个物件。未抽取用户视频或第三方游戏的图块。

内容为中式灰瓦屋舍、铁匠铺、松树、阔叶树、花树、竹丛、苔石、布棚、船、灯、围栏、芦苇、木桶、告示、货车、路标、木料、药草、木桩和营火。需求为透明独立素材、上左侧日光、高俯视、松风练剑庭院配色；生成结果的实际边界由 `world-art.mjs` 中逐件裁切坐标记录，并保持原版物件的逻辑尺寸与脚底。

NPC 继续使用本地 Canvas 程序绘制，与战斗人物共用身形；按医者、船工、商人、铁匠配置服饰与手持物。头像从相同人物绘制。

`assets/na` 保留历史资源与 CC0 来源说明，未更改原文件。
