# 正常试玩记录

正常打开 `/V0.4/`，不要加 `?debug`。继续原存档即可；升级前发生的事会标为历史缺失，不补造记录。

右上角日志 → “补充这次试玩记录”：

1. 选择操作者、招募来源和游戏经验。自动化检查必须选“自动化输入检查”；“真人试玩”是操作者自报，不是系统认证。
2. 记设备/系统/浏览器，电量、低电量与充电状态。无法确认的填未知。
3. 若别人提供提示，按实际时间记录等级与内容。系统内提示不算人工提示。没有人工提示就不添加。
4. 玩完后填卡点、自己的理解、还想试什么。先回答“发生了什么、为什么这样做”，再写好不好玩。
5. 点击“导出完整 JSON”保存本地记录；“复制这份记录”提供会话编号、操作汇总和资源差额摘要。没有上传或发送动作。

记录会区分正常入口、调试记录和历史存档续玩。任何一次调试入口都会保留调试标记，不会因回到正常 URL 而变成真人自然试玩。

自动保存中包含剧情/物品事务及逐笔差额、提示时间与战斗/练习汇总；性能按本页会话记录，刷新后不把旧帧混入新页。战斗累计未满五分钟会显示样本不足；即使累计足够，也不能替代连续五分钟实机录像。

同目录 `自动化正常输入_20261022.json` 是使用正常键盘/鼠标完成走图、拾料、与周砚交谈、制作两件剑饰和木人桩比较的检查样本。没有调试定位、无敌或跳过冷却。它不是完整章节的真人体验样本，不应计入首次完成率、真人样本人数或实机性能通过率。
